# التشغيل التلقائي على جهاز العميل (ويندوز)

تُنفّذ هذه الخطوات **على جهاز العميل فقط**. لا تحتوي السكربتات على مسار ثابت؛ تستخدم موقع المشروع الذي نُسخت إليه. أثناء التثبيت تُبنى الواجهة بـ `npm run build` مرة واحدة، ثم يخدم الباك اند ملفات `frontend/dist` وطلبات API معًا من `http://127.0.0.1:8000`؛ لا يعمل خادم Vite بوضع dev ولا يحتاج Node.js للبقاء قيد التشغيل بعد البناء.

1. ثبّت Python وNode.js على جهاز العميل، وأنشئ `.venv` جديدًا وثبّت متطلبات Python، ثم نفّذ `npm install` داخل `frontend`، وشغّل هجرات قاعدة البيانات وفق README الرئيسي. لا تنسخ `.venv` من جهاز التطوير.
2. افتح PowerShell في **جذر المشروع على جهاز العميل** ثم نفّذ:

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-autostart.ps1
   ```

3. ستبدأ الخدمة تلقائيًا عند **تسجيل الدخول إلى ويندوز** بهذا المستخدم (ليس قبل تسجيل الدخول). ولتشغيلها فورًا:

   ```powershell
   Start-ScheduledTask -TaskName AlmuraselPOS-Server
   ```

افتح `http://127.0.0.1:8000` لاستخدام التطبيق. يعمل على هذا الجهاز فقط، وتُعاد محاولة التشغيل بعد 10 ثوانٍ إذا توقفت العملية. السجل في `logs/server.log`. لا تشغّل نسخة أخرى من الباك اند على المنفذ 8000 في الوقت نفسه.

لإيقاف المهمة: `Stop-ScheduledTask -TaskName AlmuraselPOS-Server`. ولإلغاء تشغيلها تلقائيًا:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-autostart.ps1 -Remove
```

عند تحديث ملفات الواجهة، نفّذ `npm run build` داخل `frontend` مرة أخرى ثم أعد تشغيل المهمة. إذا نقلت مجلد المشروع فأزل المهمة وأعد تثبيتها من المسار الجديد. لا تفتح المنافذ للشبكة أو الإنترنت دون إعدادات نشر وحماية مناسبة.
